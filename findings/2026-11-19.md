### Deadpool (Xbox 360, 2013)
- Port: `deadpool-nx`, by BanhMi93P — static recompilation (ReXGlue) of the Xbox 360 version, rendered with reNut's Direct3D-level renderer on deko3d
- Version: **v1.0.0, released 2026-11-19** — the release ships `deadpool-nx-v1.0.0.zip` (deadpool.nro, with a complete precompiled shader cache)
- Status: released — targets 30 FPS at the console's stock clocks per its README, at 1280x720 in handheld and 1920x1080 when docked; own Xbox 360 disc files required (default.xex and the TransGame/ directory, Title ID 415608EC)
- Source: https://github.com/BanhMi93P/deadpool-nx

### Titan Souls (Android, 2015)
- Port: `TitanSouls-nx`, by siiiimooooon — Android loader (so-loader running the original ARM binary on the android32 runtime)
- Version: **v1.0.0, released 2026-11-19** — the release ships `titansouls_nx.nro`
- Status: released — tested on a Switch Lite per its README and release notes: 60 FPS at stock clocks, 720p in handheld, Switch button prompts, and the game's 27 achievements saved and viewable in its 6 languages; own Android v1.03 APK + OBB required
- Source: https://github.com/siiiimooooon/TitanSouls-nx

### SSX (Android, 2012)
- Port: `SSX-nx`, by maafeu — Android loader (the game's own ARM code runs unmodified in a 32-bit Switch process on the android32 runtime)
- Version: **source-build, published 2026-11-19** — no prebuilt GitHub release; the build, or the bundled web installer, produces the Switch package from your own SSX APK (com.ea.ssx 0.0.8430)
- Status: released (source-build) — tested on a real Switch through 2026-11-18 per its console log: World Tour, Explore, all four riders, movies and music, at 60 FPS, across about 180 loads and long sessions with no console crash since the 2026-11-18 memory fixes; the Deadly Descents / Mount Robson drops are not yet tested and the online features do nothing, per its README
- Source: https://github.com/maafeu/SSX-nx

### Medabots: Rokusho / Metabee Version (GBA, 2001/2003)
- Port: `medabots-nx`, by Niecks90 — native static recompilation (GBARecomp); dual edition: both versions in a single NRO with automatic ROM detection and separate saves
- Version: **v0.2.0, released 2026-11-19** (first release v0.1.0, 2026-11-18, covered Rokusho only) — the release ships `medabots_nx.nro`
- Status: early — 60 FPS per its README; own Rokusho / Metabee ROMs and a GBA BIOS required
- Source: https://github.com/Niecks90/medabots-nx
