# switch-ports-daily

Daily findings on unofficial Nintendo Switch game ports — fan/homebrew source ports, decompilations, Android loaders and static recompilations.

Updated every day at 6am ET (America/Toronto).

## What counts

- Unofficial ports only: source ports, decompilations, Android loaders, static recompilations.
- Official eShop releases are out of scope.
- Nothing is listed on rumour alone — rumoured / WIP items are labelled as such.
- Most 2026 builds are early (v0.1–0.5, released but not proven completable).
